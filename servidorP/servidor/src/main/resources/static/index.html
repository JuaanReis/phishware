Como ler o resultado

Cada análise termina com um veredito e uma pontuação de 0 a 100. A pontuação mede quantos sinais de risco foram encontrados. Ela não é a chance de ser golpe, e um resultado “seguro” não é uma garantia.

  • SeguroNenhum sinal relevante de risco.
  • SuspeitoHá sinais de cautela. Confirme por outro canal.
  • PerigosoVários sinais de golpe. Não clique nem pague.
  • MaliciosoIndícios fortes de conteúdo feito para causar dano.

Quando faltam dados para concluir, o resultado aparece como parcial ou inconclusivo, nunca como seguro.
